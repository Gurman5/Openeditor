# Curated Refernce point
>curated reference set, weighted toward what would feed a JUTLP-style validator/template in our project:

**Official (apa.org) — primary**
- Publication Manual 7th ed. — full structure spec (title page, abstract, headings, references): https://apastyle.apa.org/products/publication-manual-7th-edition
- What's New in 7th Ed. guide: https://apastyle.apa.org/instructional-aids/whats-new-7e-guide.pdf
- Introduction to the Manual (chapter overview): https://apastyle.apa.org/products/publication-manual-7th-edition-introduction.pdf
- Sample papers hub (student/professional, .docx + annotated): https://apastyle.apa.org/style-grammar-guidelines/paper-format/sample-papers
- Sample professional paper, annotated: https://apastyle.apa.org/style-grammar-guidelines/paper-format/professional-annotated.pdf
- Student paper annotated: https://apastyle.apa.org/style-grammar-guidelines/paper-format/student-annotated.pdf
- Student Paper Setup Guide: https://apastyle.apa.org/instructional-aids/student-paper-setup-guide.pdf
- Heading Levels Template: Student Paper: https://apastyle.apa.org/instructional-aids/heading-template-student-paper.pdf
- Heading Levels Template: Professional Paper: https://apastyle.apa.org/instructional-aids/heading-template-professional-paper.pdf
- Journal Article Reference Checklist: https://apastyle.apa.org/instructional-aids/journal-article-reference-checklist.pdf
- Journal Article Reference examples: https://apastyle.apa.org/instructional-aids/reference-guide.pdf

**Journal Article Reporting Standards (JARS) — closest analogue to our JUTLP checks**
- JARS hub: https://apastyle.apa.org/jars
- JARS–Quant Table 1 (any new data collection): https://www.pvamu.edu/cojj/wp-content/uploads/sites/31/JARS_APA_Quantitative-Data.pdf
- JARS–Qual Table 1: https://apastyle.apa.org/jars/qual-table-1.pdf
- JARS–Mixed Table 1: https://www.pvamu.edu/cojj/wp-content/uploads/sites/31/JARS_APA_Mixed-Methods.pdf
- JARS overview/slides: https://www.apa.org/education-career/training/jars-slides.pdf

**Helpful secondary quick references**
- UNC APA 7 Reference Guide (structure, headings, formatting): https://ssw.unc.edu/wp-content/uploads/sites/509/2020/10/Updated-apa-quick-reference-2020.pdf
- OHSU Quick Guide to APA 7: https://www.ohsu.edu/sites/default/files/2021-08/APA%207th%20edition%20Quick%20Guide%20updated.pdf
- Purdue OWL APA 7: https://owl.purdue.edu/owl/research_and_citation/apa_style/index.html


For the code, the most useful are the **JARS tables** and the **annotated professional sample paper** — they define required elements per manuscript section, which maps directly onto a template validator like our JUTLP one (`app/domain/`).
